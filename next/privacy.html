Privacy policy

PrintFlow, a private tool of Central Cali 3D. Updated November 13, 2026.

Who this covers

PrintFlow is used only by the owner of Central Cali 3D to run the business. It is not offered to the public and collects no information from visitors. This website serves the app's pages and does not use advertising, analytics or tracking.

What the Google Drive connection does

When the owner connects Google Drive, PrintFlow asks for one permission: to create and manage the files it creates itself (the "drive.file" permission). Each night it saves a backup of the business's own records, as a file, in a folder named CC3D-Backup in the owner's Google Drive, and deletes its own backup files older than the newest 30. It cannot see, read or change any other file in the Drive.

How Google user data is used

The only Google data involved is the backup files PrintFlow itself creates in the owner's Drive. It is used for that purpose only. It is not shared with anyone, not sold, not used for advertising, and not read by people. The access token that lets PrintFlow save to Drive is stored as a secret on the business's own server and is not shown to anyone.

PrintFlow's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Ending access

The owner can remove PrintFlow's access at any time at myaccount.google.com/permissions. Backup files already saved can be deleted from Google Drive like any other file.
